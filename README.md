# WordCards

iPhone-first PWA для изучения английских, русских и испанских слов.

## Возможности

- 10 уровней и 10 005 слов из Google Sheet
- шесть направлений перевода между English, Русский и Español
- локальный прогресс без регистрации
- режимы новых слов и повторения ошибок
- флип карточки и свайпы влево, вверх и вправо
- восстановление незавершённой сессии
- экспорт и восстановление полного прогресса через JSON-бэкап
- установка на экран iPhone и офлайн-работа

## Разработка

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run lint
npm run test:run
npm run build
```

## Данные

Нормализованный снимок таблицы хранится в `public/data/sets/`. Каждый объект слова имеет стабильный ID комплекта и три перевода. Отображаемые названия уровней находятся отдельно в `src/data/setMetadata.ts`.

Приложение читает данные через интерфейс `WordRepository`, поэтому статические JSON-файлы можно позднее заменить Vercel API, который читает приватную Google Sheet через service account.

## Deployment

Проект связан с Vercel-проектом `wordcards-kamran` и публикуется командой:

```bash
vercel deploy --prod
```
